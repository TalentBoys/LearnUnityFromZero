# 第0课：安装 Unity 与环境配置

> 本教程面向有编程基础、首次接触游戏开发的学习者。我们使用 **团结引擎**（Unity 中国版）进行开发。

---

## 0.1 什么是 Unity？

Unity 是全球最流行的游戏引擎之一，支持 2D 和 3D 游戏开发，可以发布到 PC、手机、主机、Web 等几乎所有平台。

**团结引擎**是 Unity 的中国定制版本，功能与国际版基本一致，国内下载更快，有中文支持。

### Unity 的核心组成

| 组件 | 作用 |
|------|------|
| **Unity Hub** | 管理器。管理 Unity 编辑器版本、项目、许可证 |
| **Unity Editor** | 编辑器本体。可视化的游戏开发环境 |
| **Visual Studio / VS Code** | 代码编辑器。编写 C# 脚本 |

---

## 0.2 安装 Unity Hub

### 步骤1：下载 Unity Hub

直接访问[团结引擎官网](https://unity.cn/tuanjie/releases)下载。

### 步骤2：安装 Unity Hub

1. 运行下载的安装包
2. 按默认设置一路点击 **"下一步"**
3. 安装完成后启动 Unity Hub

### 步骤3：登录账号

1. 首次打开 Unity Hub 会要求登录
2. 如果没有账号，点击 **"创建账号"** 注册一个
3. 登录后会自动激活 **个人版许可证**（Personal License，免费）

> 个人版完全免费，功能齐全，只要你的年收入/融资低于 $100K 就可以使用。

我试下来暂时不登录也可以。

---

## 0.3 安装 Unity 编辑器

### 步骤1：选择版本

1. 在 Unity Hub 左侧菜单点击 **"安装"**
2. 点击右上角 **"安装编辑器"**
3. 选择最新的 **LTS（长期支持）** 版本

> **什么是 LTS？** Long Term Support，长期支持版本，bug 更少更稳定，适合实际项目。一般选择带 "LTS" 标记的最新版本即可。

**实测中国版没有LTS标识，直接选最新版即可，我这个时候的最新版是1.8**

### 步骤2：选择组件

安装时会让你勾选额外的组件模块，建议勾选：

- [x] **Microsoft Visual Studio Community**（代码编辑器，免费）
- [x] **Windows Build Support (IL2CPP)**（打包 Windows 游戏必需）
- [ ] 其他平台支持（暂时不需要，以后可以补装）

> 安装大小约 5-10GB，确保磁盘空间充足。

### 步骤3：等待安装

安装需要一些时间（取决于网速），安装完成后会在 "安装" 页面看到已安装的编辑器版本。

---

## 0.4 创建第一个项目

### 步骤1：新建项目

1. 在 Unity Hub 左侧点击 **"项目"**
2. 点击右上角 **"新项目"**
3. 在模板列表中选择 **"3D (Core)"**

> **为什么选 3D？** 3D 模板包含了 3D 和 2D 都需要的基础功能。后续学 2D 时只需切换摄像机模式即可，不需要重建项目。

### 步骤2：设置项目信息

| 设置项 | 建议值 | 说明 |
|--------|--------|------|
| 项目名称 | `HelloWorld` | 你的第一个项目 |
| 保存位置 | 自选，如 `F:\AIGame\HelloWorld` | 选一个空间充足的盘 |

### 步骤3：创建并等待

1. 点击 **"创建项目"**
2. 首次创建会比较慢（需要导入默认资源），耐心等待
3. 创建完成后会自动打开 Unity 编辑器

## 0.5 认识 Unity 编辑器界面

打开项目后，你会看到 Unity 编辑器的主界面。初次看到可能觉得复杂，但常用的只有以下几个窗口：

```
┌──────────────────────────────────────────────────┐
│                   工具栏（Toolbar）                 │
├──────────┬───────────────────────┬────────────────┤
│          │                       │                │
│ Hierarchy│      Scene 视图       │   Inspector    │
│ 层级窗口  │    （场景编辑区）       │  （属性检查器）  │
│          │                       │                │
│          ├───────────────────────┤                │
│          │      Game 视图        │                │
│          │   （游戏预览区）        │                │
├──────────┴───────────────────────┴────────────────┤
│              Project 窗口（项目文件）                 │
│              Console 窗口（控制台/日志）              │
└──────────────────────────────────────────────────┘
```

### 各窗口的作用

| 窗口 | 快捷键 | 作用 |
|------|--------|------|
| **Scene** | - | 场景编辑区，你在这里摆放物体、搭建关卡 |
| **Game** | - | 游戏预览区，点 Play 后在这里看游戏运行效果 |
| **Hierarchy** | - | 当前场景中所有 GameObject 的树形列表 |
| **Inspector** | - | 选中物体后，在这里查看和修改它的所有属性 |
| **Project** | - | 你的项目文件管理器（脚本、材质、贴图等都在这里） |
| **Console** | Ctrl+Shift+C | 查看 Debug.Log 输出和错误信息 |

### Scene 视图操作

在 Scene 视图中导航是最常用的操作：

| 操作 | 方式 |
|------|------|
| **旋转视角** | 按住鼠标右键 + 拖动 |
| **平移视角** | 按住鼠标中键 + 拖动 |
| **缩放** | 滚轮 |
| **聚焦物体** | 在 Hierarchy 中选中物体，按 **F** 键 |
| **飞行模式** | 按住右键 + WASD 移动（像玩FPS游戏一样） |

## 0.6 配置代码编辑器

Unity 的脚本使用 C# 语言编写，你需要一个代码编辑器来写代码。

### 推荐选择

| 编辑器 | 优势 | 适合 |
|--------|------|------|
| **Visual Studio Community** | Unity 安装时自带，调试功能强 | 新手首选 |
| **VS Code** | 轻量快速，插件丰富 | 喜欢轻量编辑器的人 |
| **JetBrains Rider** | 最智能的 C# IDE，重构强大 | 追求效率（付费） |

### 在 Unity 中设置代码编辑器

1. 打开 Unity 编辑器
2. 菜单栏 → **Edit** → **Preferences**（或 macOS 上 **Unity** → **Settings**）
3. 左侧选择 **External Tools**
4. **External Script Editor** 下拉菜单中选择你安装的编辑器
5. 之后双击脚本文件时，会自动用你选择的编辑器打开

## 0.7 推荐的项目文件结构

创建项目后，建议在 `Assets` 文件夹下建立以下目录结构，保持项目整洁：

```
Assets/
├── Scripts/          # C# 脚本
├── Scenes/           # 场景文件
├── Prefabs/          # 预制体
├── Materials/        # 材质
├── Textures/         # 贴图
├── Animations/       # 动画
├── Audio/            # 音效和音乐
└── UI/               # UI 资源
```

在 Unity 编辑器的 **Project** 窗口中：
1. 右键点击 `Assets` 文件夹
2. 选择 **Create → Folder**
3. 依次创建上面列出的文件夹

> 现在不需要全部创建，用到哪个建哪个即可。`Scripts` 文件夹是首先需要的。

## 0.8 验证安装

让我们做一个简单的验证，确保一切正常：

### 测试1：创建一个物体

1. 在 Hierarchy 窗口中，右键 → **3D Object** → **Cube**
2. 你应该能在 Scene 视图中看到一个白色的立方体
3. 点击选中它，Inspector 中会显示它的 Transform（位置、旋转、缩放）

### 测试2：运行游戏

1. 点击编辑器顶部中央的 **▶ Play 按钮**
2. 切换到 Game 视图，你应该能看到立方体
3. 再次点击 **▶** 停止游戏

### 测试3：打开 Console

1. 菜单栏 → **Window** → **General** → **Console**（或按 Ctrl+Shift+C）
2. 确认 Console 窗口已打开，后续我们会频繁用它查看日志

如果以上三步都正常，恭喜你，环境已经就绪！

## 0.9 小贴士

- **经常保存**：Ctrl+S 保存场景。Unity 没有自动保存，崩溃了就白做了
- **Play 模式下的修改不会保存**：这是新手最常踩的坑！在 Play 状态下调参数，停止后会全部重置。养成习惯：调完参数 → 停止 Play → 再调一次
- **Console 是你最好的朋友**：遇到问题先看 Console 有没有红色报错
- **善用 Ctrl+Z**：Unity 的撤销很好用，大胆尝试不怕搞坏
